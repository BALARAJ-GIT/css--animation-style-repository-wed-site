Motion is the interface.

A working bench of CSS-only motion — timing curves, hover states, loaders and a morphing shape — built to test how a prototype should feel before it ships. No JavaScript, just @keyframes, transition and a lot of small adjustments.

A radial pulse expands from center on :active, pure CSS, no click handler.

§4

Continuous morph

One shape, two looping animations layered together — border-radius drifting on a long clock, rotation on a slower one, so it never quite repeats.

/* the whole effect, two rules */

.blob {
  animation:
    blob-morph 7s ease-in-out infinite,
    blob-spin 14s linear infinite;
}

@keyframes blob-morph {
  0%, 100% { border-radius: 42% 58% 65% 35%
                        / 45% 40% 60% 55%; }
  34%      { border-radius: 63% 37% 41% 59%
                        / 55% 65% 35% 45%; }
  67%      { border-radius: 38% 62% 55% 45%
                        / 62% 38% 62% 38%; }
}
